# FitPlan 1.9.7 — 알림 기능

- 모든 카운트다운 타이머 종료 5·4·3·2·1초에 1초 간격의 짧은 알림음
- 0초에는 큰 종료 알림음 및 진동(기기 지원 시)
- 휴식 종료 후 같은 종목의 다음 세트 자동 시작
- 다른 종목 시작 시 사용자 시작 버튼 대기

## APK 게시 절차

1. GitHub Releases에서 새 릴리스 생성: 태그 `fitplan-v1.9.7`, 제목 `FitPlan 1.9.7`.
2. APK 자산으로 `FitPlan_1.9.7_Alarm.apk` 첨부 및 게시.
3. APK 자산이 실제 공개 상태인지 검증.
4. 검증 후에만 `fitplan/latest.json`을 1.9.7과 실제 다운로드 URL로 갱신.

**주의:** 1.9.7은 1.9.6 별도 시험판 패키지 계열로 빌드되어 1.9.5 정식 앱과 패키지/서명이 다릅니다. `latest.json`을 1.9.7로 올리기 전, 정식 1.9.5에 덮어 설치 가능한 빌드를 만들거나 호환성을 반드시 확인해야 합니다.
